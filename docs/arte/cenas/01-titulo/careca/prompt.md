# Cena 01 — Título — corte Careca

**Usada em:** Evento de título (estadual, copa, liga). Jogador de costas apontando para o céu, taça ao fundo.

**Antes de gerar:** anexe no Gemini a imagem-base desta cena (`../curto/imagem.jpeg`).

**Arquivo da imagem:** salve nesta pasta como `imagem.jpeg`.

## Prompt

```
Edit the attached image. Change only the hair of the main character (the player in the magenta shirt seen from behind): give him a completely shaved, bald head with no hair at all.

Keep everything else exactly as it is in the attached image: the same pose, body, skin tone, magenta shirt, cyan shorts and socks, background, lighting, colours, painting style and composition. Keep the same vertical 4:5 format and the same framing. Do not move, add or remove anything else.

The back of the magenta shirt must stay completely blank and uncovered: the hair must not hang over the area between the shoulder blades more than a few centimetres below the collar. Do not add any text, numbers, logos or watermark.
```

## Conferência

- [ ] Só o cabelo mudou; cena, pose e cores iguais à imagem-base
- [ ] Cabelo no corte pedido
- [ ] Costas da camisa continuam lisas e livres para o número
- [ ] Sem texto, número, escudo, logo ou marca d'água
