# Piloto das cabeças de costas (2026-10-15)

Cena 11 (treino) do Athletico, lote 01, com o curto atual como base. Pela API (`gpt-image-2`, edit, 1024×1536) só o
formato do cabelo muda; a referência de cada formato é o retrato aprovado em `docs/arte/visuais-base/`. Cinco chamadas,
uma tentativa cada, cerca de US$ 0,44 (US$ 0,087 por imagem, `piloto.json`). Script: `../piloto_cabecas.py`.

| Formato | Referência |
|---|---|
| raspado | `v1-raspado` |
| médio ondulado | `v1-medio` |
| longo liso | `v1-longo` |
| cacheado médio | `v3-medio` |
| cacheado grande | `v3-longo` |

Cor do cabelo e pele seguem por código. Os dois cacheados vieram mais escuros que o castanho médio da base.
