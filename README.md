# 10eFaixa

Simulador de carreira do futebol brasileiro: da várzea, peneira ou base até a aposentadoria.

## Comandos
- `npm run dev` servidor local
- `npm test` testes (Vitest)
- `npm run typecheck` TypeScript estrito
- `npm run build` build de produção

## Aviso
Projeto independente, sem afiliação a clubes, ligas ou federações. Jogadores são fictícios.
